Setup notes

This prototype loads assets/sherpa/asr/sherpa-onnx-wasm-main-asr.{js,wasm,data} + sherpa-onnx-asr.js (shared with production). The .wasm and .data files are gitignored (11MB + 183MB).

Re-download:

cd assets/sherpa/asr
for f in sherpa-onnx-asr.js sherpa-onnx-wasm-main-asr.js \
         sherpa-onnx-wasm-main-asr.wasm sherpa-onnx-wasm-main-asr.data; do
  curl -L -O "https://huggingface.co/spaces/k2-fsa/web-assembly-asr-sherpa-onnx-en/resolve/main/$f"
done

Serve over HTTP (mic + WASM need a real origin):

python3 -m http.server 8000
# then open http://localhost:8000/workbench/stt-prototype/

The bundled model is k2-fsa's full LibriSpeech zipformer (~191MB packed). For production we'll rebuild WASM with the 20M streaming zipformer (~45MB).
